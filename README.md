# 🔍 Red Team Enumeration Lab

## 📖 About This Project

This repository documents my practical learning journey in offensive security and penetration testing.

The focus of this lab is reconnaissance and enumeration using Kali Linux and Nmap.

---

# 🛠️ Tools Used

- Nmap
- Kali Linux
- NSE Scripts

---

# ⚡ Skills Practiced

- Port Scanning
- Service Detection
- Enumeration
- Information Gathering
- Network Reconnaissance

---

# 🔎 Example Commands

```bash
nmap -sV TARGET-IP

nmap -A TARGET-IP

nmap --script vuln TARGET-IP

nmap -p- TARGET-IP
```
